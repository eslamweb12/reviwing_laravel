what is the facade ?
In Laravel, a Facade is a design pattern that provides a static interface to classes available in the application's service container. Facades serve as 
"static proxies" to underlying classes in the service container, providing a concise and expressive way to access Laravel's features without needing to manually 
resolve dependencies or instantiate objects.



**how to create a facade in you app?
make folder and call it facades in the app folder

make a file and call it CustomeFace 

like this
<?php
namespace App\facades;

class CustomFacade extends Facade{  // every facade class should extend the facade class
    /**
     * Get the registered name of the component.
     *
     * @return string
     */
    protected static function getFacadeAccessor()    // this function should be in every facade 
    {
        return 'custom-facade';
    }

}

?>
