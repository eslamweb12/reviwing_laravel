In Laravel, Route Model Binding is a powerful feature that allows you to automatically inject model instances directly
 into your route callbacks or controller methods. This eliminates the need to manually query the database for the model
 instance based on the route parameter


**we have two kinds of the route model binding
 1-Implicit Binding   2-Explicit Binding.


**1-Implicit Binding:Implicit binding is the simplest form of route model binding. Laravel automatically resolves the model 
instance based on the route parameter name and type-hinted variable in the controller method.

in the rouest 
Route::get('/users/{user}', [UserController::class, 'show']);

in the controller
public function show(User $user)
{
    // Laravel automatically fetches the User model instance based on the {user} parameter
    return view('users.show', ['user' => $user]);
}
**2-Explicit Binding:Explicit binding allows you to customize how Laravel resolves the model instance. For example, 
you might want to use a column other than id (e.g., username or slug) to fetch the model.


to do this binding 
1-Step 1: Define the Binding
in the routeServiceProvider
use App\Models\Post;
use Illuminate\Support\Facades\Route;

public function boot()
{
    parent::boot();

    // Explicit binding: Use 'slug' instead of 'id' to resolve the Post model
    Route::model('post', Post::class, function ($value) {
        return Post::where('slug', $value)->firstOrFail();
    });
}

Route::get('/posts/{post}', [PostController::class, 'show']);


// app/Http/Controllers/PostController.php
public function show(Post $post)
{
    // Laravel will resolve the Post model using the 'slug' column
    return view('posts.show', ['post' => $post]);
}
