what is the dependancy injection ? 
dependancy injection used when you want to inject class or to use a class in another class without using make 
and object 
for EX:
 class car{
  public function buy($string){
   dd($string);
  }
  
 
 }

 class another{
    public function __construct() {
        $this->car = new Car(); // Initialize the Car object
    }

    public function doSomething() {
        $this->car->buy('image'); // Call the `buy` method on the Car object
    }

  }
